# v0.2.0 Version and Build Identity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every ChangeSafe workspace package and runtime build identity to `0.2.0` while preserving policy identities and byte-for-byte verification of the published v0.1.0 snapshot.

**Architecture:** Treat release identity and policy identity as separate version families. A manifest contract test enumerates every workspace and internal dependency edge before any versions move. CLI and app build identities then follow their package versions, while the historical verifier explicitly replays the v0.1.0 snapshot with its recorded `changesafe-cli-0.1.0` identity.

**Tech Stack:** npm 10.9.8 workspaces, strict TypeScript, Vitest, bundled Node 22 CLI, Next.js.

## Global Constraints

- Execute `docs/superpowers/plans/2026-07-27-benchmark-report-corpus-integrity.md` first so v0.2.0 does not package a misleading benchmark artifact.
- Base this work on `main` at or after `fedd6d0`, where release-plan PR1 and PR2 are merged.
- Every root/workspace manifest moves from `0.1.0` to `0.2.0`.
- Every internal `@changesafe/*` dependency and devDependency uses `^0.2.0`, matching the adopted release-plan assumption that compatible `0.2.x` patches need not move in lockstep.
- `@changesafe/ai`, `@changesafe/ledger`, and `@changesafe/server` remain `private: true`; changing their version does not publish them.
- `CORE_POLICY_VERSION`, `NETWORK_POLICY_VERSION`, `TERRAFORM_POLICY_VERSION`, the network/terraform composed `POLICY_VERSION` values, and `lib/domain/version.ts`’s legacy test-fixture `POLICY_VERSION` remain unchanged.
- `scripts/lib/v0.1.0-release.mjs` remains pinned to `changesafe-cli-0.1.0`; it describes a historical signed artifact, not the current build.
- No npm publication, tag, GitHub release, secret configuration, or moving `v0` tag in this plan.
- Rebuild and commit `packages/cli/dist/changesafe.js`.
- Default tests use no provider credentials, network calls, or API credit.

- [ ] **Step 1: Replace ad hoc manifest reads with a validated manifest registry**

In `tests/integration/version-sync.test.ts`, add Zod and define:

```ts
import { z } from "zod";

import { CLI_APP_VERSION, SERVER_APP_VERSION } from "changesafe/version";

const TARGET_VERSION = "0.2.0";
const TARGET_INTERNAL_RANGE = "^0.2.0";

const ManifestSchema = z.object({
  name: z.string().min(1),
  version: z.string().min(1),
  private: z.boolean().optional(),
  dependencies: z.record(z.string(), z.string()).optional(),
  devDependencies: z.record(z.string(), z.string()).optional(),
});

const MANIFEST_PATHS = [
  ".",
  "packages/ai",
  "packages/cli",
  "packages/core",
  "packages/domain-network",
  "packages/domain-terraform",
  "packages/ledger",
  "packages/server",
] as const;

const PUBLISHABLE_PACKAGE_PATHS = [
  "packages/cli",
  "packages/core",
  "packages/domain-network",
  "packages/domain-terraform",
] as const;

const DEFERRED_PRIVATE_PACKAGE_PATHS = [
  "packages/ai",
  "packages/ledger",
  "packages/server",
] as const;

function readManifest(relative: string) {
  return ManifestSchema.parse(
    JSON.parse(
      readFileSync(path.join(root, relative, "package.json"), "utf8"),
    ),
  );
}

function internalRanges(manifest: z.infer<typeof ManifestSchema>) {
  return Object.entries({
    ...manifest.dependencies,
    ...manifest.devDependencies,
  }).filter(([name]) => name.startsWith("@changesafe/"));
}
```

Remove the old unvalidated `readVersion(...)` helper.

- [ ] **Step 2: Add failing release-version and dependency-range tests**

Add:

```ts
describe("v0.2.0 workspace release identity", () => {
  it("moves every root and workspace manifest together", () => {
    for (const relative of MANIFEST_PATHS) {
      expect(
        readManifest(relative).version,
        `${relative}/package.json version`,
      ).toBe(TARGET_VERSION);
    }
  });

  it("uses the adopted compatible 0.2.x range on every internal edge", () => {
    for (const relative of MANIFEST_PATHS) {
      for (const [dependency, range] of internalRanges(readManifest(relative))) {
        expect(range, `${relative} -> ${dependency}`).toBe(TARGET_INTERNAL_RANGE);
      }
    }
  });

  it("publishes only the CLI, core, and two selected domains", () => {
    expect(readManifest(".").private).toBe(true);
    for (const relative of PUBLISHABLE_PACKAGE_PATHS) {
      expect(readManifest(relative).private, relative).not.toBe(true);
    }
    for (const relative of DEFERRED_PRIVATE_PACKAGE_PATHS) {
      expect(readManifest(relative).private, relative).toBe(true);
    }
  });
});
```
